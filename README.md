# Moava

> **Every little win moves you forward.**

Moava is a parent-and-child app that helps families build healthy money habits by turning everyday chores into shared progress.

**Designed and built end-to-end by Mina Ryu**, from product strategy and UX/UI to implementation.

## 🎬 Demo

<img width="400" alt="moava-demo" src="https://github.com/user-attachments/assets/1133f2a6-ad93-4448-baf9-a8c215092ec6" />


## ✨ Features

- ✅ Complete missions with parent approval
- 💬 Share notes between parent and child
- 🎯 Save toward personalized goals
- ⭐ Earn XP and celebrate progress together
- 👪 Build healthy money habits as a family

## 🛠 Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
- AI-assisted development with Cursor
